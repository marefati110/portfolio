# marefati110.ir

Personal site of Ali Marefati. Next.js 16 (App Router), fully static, English only.

- Content: `content/site.ts`, kept in sync with `~/w/cv/versions/master.html`.

```bash
pnpm dev                 # http://localhost:3000
pnpm build && pnpm start
```
